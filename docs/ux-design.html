Custom, not complicated

  • 5-minute 4–4–4–4 is ready immediately
  • Each of four phases adjusts independently
  • 4–4–6–4 is available as a one-tap preset
  • Cycle count and guided pace recalculate instantly

Safe interruption

  • Pause is always reachable with one tap
  • Resume restarts the interrupted phase after a countdown
  • End requires a lightweight confirmation
  • App backgrounding enters a clear paused state

Health context, by consent

  • Practice works fully without a wearable
  • HealthKit and Health Connect aggregate supported devices
  • HR, HRV, resting HR, breath rate, SpO₂, and sleep are read-only
  • Missing samples stay unavailable—never estimated

Design handoff

Rules that survive implementation

These are the non-negotiable interaction details to carry into the React Native build.

Visual source

The branding board is canonical for palette, typography, logo, and icon. This prototype is canonical for screen hierarchy, state treatment, and interaction behavior.

Typography

Use Newsreader for display moments and DM Sans for interface copy. Respect Dynamic Type. Never truncate a phase label, countdown, safety message, or primary action.

Phase palette

Use quiet sky for inhale, saffron for the first hold, living coral for exhale, and mist for the recovery hold. Always retain the phase number, name, countdown, motion state, tone, and haptic so color is never the only cue.

Contrast

Maintain WCAG AA. The practice screen uses bright type on deep green; phase meaning never depends on color alone.

Motion

The breathing form expands and contracts slowly. With reduced motion, hold the shape still and retain the number, label, tone, and haptic.

Haptics

Use distinct but gentle phase-boundary patterns. Unsupported devices fail silently; haptics never become required.

Guidance rollout

Keep the test build to tones and haptics. After pacing and cue comprehension are validated, record the phase prompts, add voice as an optional cue, regression-test all cue combinations, then launch.

Timer

Store four independent 1–20 second phase durations. The MVP offers 1, 3, 5, and 10 minute sessions. Animation reads timer state; it does not own it. Begin and resume use a three-second neutral countdown.

MVP focus

Ship the breathing loop, onboarding, accessible optional setup, local history, settings, and optional health-session writing first. Recorded voice, reminders, wearable reads, biometric comparisons, trend charts, streaks, and tablet-specific layouts must not delay launch.

Controls

Use at least 44×44 pt targets on iOS and 48×48 dp on Android. Distinguish “Hold after inhale” from the recovery “Rest” in visible labels and assistive announcements.

Health layer

Read wearable data through HealthKit on iOS and Health Connect on Android. Do not add direct Apple Watch, Fitbit, Pixel Watch, or Galaxy Watch SDKs for MVP.

Indicators

Request heart rate, HRV, resting heart rate, respiratory rate, SpO₂, and sleep as separate read-only categories. Store timestamped heart and respiratory samples that overlap the practice window; label them live or delayed. Show a latest historical sample separately, never as a session measurement.

Progression

Offer 7- and 30-day views for resting HR, HRV, and mindful minutes. Compute before/after HR, pattern totals, and streaks only from available records; render gaps as gaps.

Permissions

Explain each read category and the breathing-session write scope before the native prompt. Denial or missing wearable data never blocks practice.

Copy

Say “practice,” “session,” and “wellbeing.” Avoid treatment claims, guilt, productivity pressure, and language that judges consistency.
