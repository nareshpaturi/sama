Interaction contract

02 / Journey

Ready first.
Adjust when you want.

A returning user can start with one primary action. Optional customization never becomes a required setup step.

01 / Breathe

Ready to begin.

Default or last-used pattern; actual whole-cycle duration visible.

02 / Settle

Three quiet seconds.

Neutral count. Cancel returns without creating a record.

03 / Practice

One phase at a time.

Label, count, remaining time, Pause, and End.

04 / Finish

Acknowledge the pause.

Save locally, then offer Done, Breathe again, and optional Health.

First use

Welcome → comfort → cue preferences → Breathe. Three short steps; no Health permission or account creation. Settings repeats the comfort guidance and cue controls.

Optional customization

Breathe → Customize practice → target duration and phase controls → Use this rhythm → Breathe. Preserve changes when leaving setup; Begin remains on Breathe.

Duration contract: cycle seconds = the sum of four phases. Planned cycles = round up (target seconds ÷ cycle seconds). Planned practice time = cycles × cycle seconds. A 5-minute 4–4–4–4 practice is 19 cycles / 5:04; 4–4–6–4 is 17 cycles / 5:06. Resuming a partially used phase can extend actual practice time. Summary reports actual active time and only complete cycles.
03 / State contract

Calm includes the edges.

The same hierarchy holds when someone pauses, ends early, declines Health, or cannot save a record. No state should imply a result that has not happened.

04 / Guidance & accessibility

The rhythm stays predictable.

The guide supports the phase; the timer remains authoritative. These are handoff rules. The viewer deliberately shows still frames.

01 / Inhale

Sky. Expand from the small resting size to the full guide across the selected phase.

02 / Hold after inhale

Saffron. Keep the guide full and still for the selected count.

03 / Exhale

Coral. Contract across the selected phase to the small resting size.

04 / Rest

Mist. Stay small and still. This is the pause after exhaling.

Motion follows the count.

Use a continuous, gentle curve without spring overshoot or decorative pulsing. Start and stop with the phase boundary; pause freezes guidance. Scene changes use a short opacity transition, with no slide or zoom.

Reduced motion: fixed-size guide for every phase; retain text and countdown, with optional tones and haptics. Follow the system preference on first use; a user override can only reduce motion.

Every cue has a fallback.

Announce the phase name and selected seconds once at each boundary. Avoid a screen-reader announcement every second. Labels, numerals, tone, and optional taps provide complementary guidance.

Honor audio preferences and platform behavior. Haptics may be unsupported; practice must still work. Validate cue distinction on physical devices before release.

Accessibility handoff: 48 × 48 mock targets; 52 px primary controls; visible keyboard focus; scalable text; scrollable content; safe-area insets. Never truncate Hold after inhale, a safety message, or an action. Verify real VoiceOver/TalkBack, system reduced motion, and 100/150/200% text sizing during later implementation.
